# 포트폴리오 리디자인 설계

2026-08-03. 대상: evergreentree97.github.io (React + Vite, 픽셀 아트 컨셉).

## 목표

배경을 모르는 사람도 첫 화면에서 "이 사람이 누구고 뭘 하는 사람인지" 알 수 있게 만들고,
AI가 쓴 티가 나는 문구를 걷어내고, 초록 테마와 게임스러운 모션으로 심미성을 끌어올린다.

## 결정 사항

- 픽셀 아트(도트) 컨셉은 유지하고 다듬는다. 전면 리디자인은 하지 않는다.
- 애니메이션은 게임스럽게 풍성하게 간다. 라이브러리 추가 없이 CSS와 IntersectionObserver로 구현한다.
- 톤: 제목은 말 걸듯 시선을 끄는 훅, 본문은 전문적이고 건조한 사실 서술.

## 1. 콘텐츠

- Hero 제목: "채팅 앱 만들던 사람이 왜 모델을 학습하냐면요" 계열의 대화형 훅.
  서브 문구는 사실로 받친다: Levvels에서 Vuddy 채팅과 Momentica를 만들었고,
  오픈소스 LLM의 학습과 평가를 맡고 있다는 내용.
- 본문(프로젝트, 경력, 기술)은 전문적인 서술을 유지하되 이력서 요약체를 읽히는 문장으로 다듬는다.
- 각 섹션 도입에 한 줄 안내문을 붙여 처음 온 사람도 섹션의 목적을 알게 한다.
- 금지: "A부터 B까지", "A하다가 B합니다" 같은 대구법, 번역투, U+2014, U+00B7.
- 기여 등급(career/evidence-master.md)을 넘는 문장을 만들지 않는다.
  수치의 채점 주체와 표본 표기는 유지한다. AI 평가 수치는 내부 자동 평가 결과임을 밝힌다.
- 전체 문구는 humanizer 기준으로 2회 검수한다.

## 2. 초록 테마

- 3단 그린 팔레트: 배경은 아주 연한 민트 크림, 주 액센트는 선명한 리프 그린,
  포인트는 짙은 포레스트 그린.
- 다크 픽셀 프레임과 CRT 스캔라인풍 미세 텍스처로 레트로 게임 감성을 강화한다.
- 헤딩 픽셀 폰트(Silkscreen)는 유지하고 본문 타이포 대비를 키운다.

## 3. 모션

- Hero: 타이핑 커서, CSS steps() 기반 스프라이트풍 모션, 상태 박스가 게임 HUD처럼 뜨는 등장 효과.
- 스크롤: 픽셀 블록이 조립되듯 나타나는 stagger reveal. 기존 Reveal 컴포넌트를 확장한다.
- 호버: 버튼과 카드에 픽셀 점프와 8bit 그림자 이동. 프로젝트 카드는 선택 프레임 깜빡임.
- ProofStrip 숫자 카운트업, 스킬 태그는 게임 인벤토리 슬롯풍.
- `prefers-reduced-motion`을 존중해 모션을 끈 사용자에게는 정적 표시로 대체한다.

## 4. 검증

- `npm run check`(lint + build) 통과.
- `npm run dev`로 실제 렌더를 확인하고 스크린샷으로 보고한다.
- 배포(push)는 사용자 확인 후 별도로 진행한다.
