# Portfolio Project Context

공개 포트폴리오 사이트다.

- 포트폴리오 작업은 `docs/portfolio/README.md`에서 시작하고, 공개 기준은 `docs/portfolio/content.md`를 따른다.
- 구현과 배포 방법은 `README.md`를 따른다.
- 수정 후 `npm run check`를 실행한다.

## Writing and visual review

- Before authoring visible copy or reporting changes, follow `docs/portfolio/plain-language.md`. The user's rejected phrases are regression cases, not templates to paraphrase.
- Keep text grounded in a named object, action and verified responsibility. Delete layout commentary and generic promises when they add no information.
- New copy must pass `npm run check:copy` and a sentence-level human review. A clean pattern scan does not establish writing quality.
- After a visual redesign, inspect current desktop and mobile renders. Review typography, hierarchy, density and actual images independently of build checks. A user rejection overrides an earlier positive review.
